一、快速上手（三步）

  1. 填写课程名称 —— 用于命名输出文件夹与文档（同名课程再次录制会自动加序号，如 课程-1、课程-2，不会互相覆盖）。
  2. 点「● 开始录制」 —— 软件自动录制电脑正在播放的课程声音并实时转成字幕。首次使用会先下载语音模型（约 483MB，仅一次，之后完全离线）。
  3. 点「■ 停止」 —— 自动生成图文逐字稿，可一键导出 Word，或用 AI 梳理成结构化教程文档。
录制时你尽可以去操作播放器、看网页：暂停/停止/截图都有全局快捷键，窗口在后台也有效。

二、录制控制

操作界面按钮全局快捷键说明
开始录制● 开始录制—录制系统声音（无需麦克风），实时逐句转文字
暂停 / 继续⏸ 暂停 / ▶ 继续F10暂停期间不录音、不推进时间轴
停止■ 停止F11生成逐字稿；收尾期间界面会提示进度
截图📷 手动截图F9立刻保存当前画面（录制中任意时刻可用）

声音电平条：实时显示系统声音强度。若一直是 0，说明课程声音没有从「正在录制的设备」播放（见常见问题 Q1）。

采集来源（主界面下拉框）

  • 跟随设置：按设置里的默认（整个显示器或固定区域）。
  • 🖥 屏幕：截取指定显示器的完整画面（含其他弹窗）。
  • 🪟 窗口：只截取所选应用自身的界面——即使被其他窗口遮挡、弹出广告，截到的都只有课程画面。推荐网课使用。

三、截图：手动 / 自动随时切换

开关在主界面：「📷 手动截图」按钮旁边的「自动截图」勾选框，录制中也能随时切换，即时生效。

  • 不勾选（默认）：全靠手动截图。F9 或按钮，想截就截，逐字稿里按时间轴插图。
  • 勾选自动截图：软件持续监测画面，页面变化率超过阈值（默认 10%）时自动保存一张——翻页、滚动、大段板书会触发；光标移动、弹幕、水印这类小变化不会触发。阈值可在【设置 → 截图方式】调整。
  • 两种模式互不影响：自动开着时按 F9 照样手动截。

切换 PPT 时短暂出现的全黑/全白过渡帧会被自动丢弃，不会混进文档。

四、导出

导出方式菜单入口说明
Word 逐字稿导出 → 导出 Word 逐字稿段落式图文逐字稿，截图按时间轴插入
AI 结构化教程导出 → 生成 AI 教程文档用大模型把逐字稿整理成「教程」——分章节、要点、步骤（需在设置里配置 API Key）
离线重转写导出 → 离线重转写用大模型重新转写 audio.wav，准确率更高（CPU 上较慢，适合课后慢慢跑）

五、设置

  • 语音识别：实时模型档位（small 够用且快）、离线重转写档位（large-v3 最准）、HF 下载镜像（国内建议 https://hf-mirror.com）。
  • 翻页检测：自动截图触发阈值、内容区 ROI（把播放器控制栏/弹幕区排除出画面判断）。
  • AI 梳理 (LLM)：服务商预设（智谱/DeepSeek/通义/OpenAI/自定义），API Key 以 Windows 加密方式保存。
  • 输出：输出目录、是否保留 audio.wav（留着的才能离线重转写）、界面主题。

六、输出文件在哪

状态栏右下角有 📁 输出目录 链接（悬停可看完整路径，点击直接打开）。每次录制一个文件夹：

输出目录/
└─ 2026-11-22_19-30-00_机器学习第3讲/
   ├─ transcript.md      ← 图文逐字稿（Markdown）
   ├─ 机器学习第3讲.docx  ← 导出的 Word
   ├─ audio.wav          ← 原始录音（可离线重转写）
   ├─ events.jsonl       ← 事件流（崩溃后可自动恢复）
   └─ screenshots/       ← 截图

【帮助 → 历史会话】可查看/重新导出以往的任何一次录制。

七、常见问题

Q1 电平条一直是 0 / 转写没有文字？

课程声音必须从「正在播放的默认输出设备」出声。换个播放设备（如从扬声器切到耳机）后重新开始录制即可。另外首次使用需先下载语音模型，下载进度会自动弹出。

Q2 蓝牙耳机突然断连，录音会坏吗？

不会。软件检测到设备断开会自动等待恢复（状态栏有提示），耳机重新连接后接着写同一个录音文件，时间轴连续；超过 90 秒未恢复才自动结束本次录制，断开前的内容完整保留、逐字稿照常生成。

Q3 下载模型很慢 / 失败？

【设置 → 语音识别 → 模型下载】把 HF 镜像填为 https://hf-mirror.com 后重试。支持断点续传，中断后再次下载会接着传。

Q4 软件中途被强制关闭（断电/闪退），内容丢吗？

不丢。录制过程逐条写入事件流（events.jsonl），重新打开软件会自动恢复会话，可在【历史会话】里重建逐字稿。

Q5 快捷键按了没反应？

F9/F10/F11 是系统级全局热键，可能被其他软件占用。窗口底部会提示哪些键注册失败——被占用的键请直接用界面按钮。

Q6 GPU 加速？

有 NVIDIA 显卡且装好 CUDA 运行库时自动用 GPU，否则自动用 CPU（不影响功能，只影响速度）。日志会明确写出当前使用的设备。
