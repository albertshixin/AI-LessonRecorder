> **内测试用版 · v1.3.0 · Windows**

各位好！我最近开发了一款 Windows 桌面小工具——**在线课程录播器（AI LessonRecorder）**，现在开放给群内朋友免费试用。本版已支持**「AI 把逐字稿总结成结构化教程文档」**（需在设置里填一个大模型 API Key），录音、翻页截图、逐字稿导出等功能全部可用。欢迎大家试用并把问题反馈给我，我会持续改进。

## 一、为什么要做这个软件？——它解决的痛点

看在线课程（技术培训、网课、行业分享）时，你是不是也遇到过这些问题：

| 痛点 | 现实场景 |
|------|----------|
| **记不住、找不到** | 两小时的课听完就忘，回头想找"老师讲某个知识点的部分"，只能拖着进度条一遍遍找 |
| **截图+笔记对不上** | 手动截 PPT、手动记笔记，截图存了一堆，但不知道哪句话对应哪页 PPT |
| **录屏文件太大没法用** | 录了整个视频文件，几 GB 起，没法搜索、没法二次整理 |
| **边看边记根本忙不过来** | 一边盯播放器一边打字，笔记记不全，课也没看好 |
| **课后整理耗时巨大** | 想把课程整理成复习资料，光听写逐字稿就要花掉比看课更长的时间 |

**这款软件的答案：让电脑替你听课、记笔记、截 PPT。**

你只管正常看课，它在后台同时做三件事：录下系统声音并**实时转成带时间戳的逐字稿**、自动检测 **PPT 翻页并截图**、把截图**按时间戳插入到逐字稿对应位置**。下课时，一份"文字 + PPT 截图混排"的完整课程记录就自动生成了，还能一键导出 Word。

## 二、软件简介

一句话：**一款边看课边自动生成图文并茂课程笔记的工具**。

录制流程：

```
你正常看课
   │
   ├─→ 录制电脑声音 ──→ 实时语音转文字（带时间戳）
   │
   └─→ 定时抓屏 ──→ 自动检测 PPT 翻页 ──→ 翻页即截图
                          │
点"停止" ──→ 自动生成逐字稿（文字 + PPT 截图按时间轴混排）
                          │
              一键导出 Word 逐字稿文档
```

核心能力一览：

| 功能 | 说明 |
|------|------|
| 🎙️ 系统声音录制 | 直接录电脑播放的声音，**不需要麦克风、不怕环境吵** |
| 📝 实时转文字 | 边录边出字幕，带时间戳；本地 AI 模型离线运行，**课程内容不出你的电脑** |
| 🖼️ 智能翻页检测 | 图像算法自动判断 PPT 翻页，翻页才截图，不存冗余画面；翻回旧页不会重复截图 |
| 🪟 只截课程窗口 | 可选"窗口采集"模式，只截课程播放器界面，弹窗、微信消息遮挡也不影响 |
| 🕐 时间轴同步 | 每张截图自动插到逐字稿中"正在讲这页 PPT"的位置 |
| 📄 一键导出 Word | 图文混排的 Word 逐字稿，可直接归档、转发、二次编辑 |
| 🔁 离线重转写 | 下课后可以用更大的 AI 模型把整节课重新转写一遍，显著提升准确率 |
| 🔒 数据本地化 | 录音、逐字稿、配置全部保存在本机；API Key 加密存储 |

## 四、安装步骤

**不需要安装 Python、不需要任何环境配置**，三步搞定：

1. **解压**：把下载的 zip 解压到任意目录（建议放到如 `D:\Tools\` 下，别放在需要管理员权限的系统目录）
2. **运行**：双击解压目录里的 **`在线课程录播器.exe`**
3. **首次等待**：第一次点"开始录制"时会自动下载语音识别模型（约 483MB，国内镜像加速、支持断点续传），下载一次永久使用，之后秒开

> ⚠️ 如果 Windows SmartScreen 提示"已保护你的电脑"，点"更多信息"→"仍要运行"即可（软件没有购买代码签名证书，属正常现象）。

## 五、使用教程

### 1. 开始前：选择采集来源（重要）

软件支持两种模式，启动后在控制面板顶部选择：

- **屏幕模式**：截取整个屏幕。适合 PPT 全屏播放的课程
- **窗口模式**：只截取选定的应用窗口（如浏览器里的课程播放器）。**推荐**——就算有微信弹窗、其他窗口遮挡，截图始终是干净的课程画面

### 2. 录制（全程不用切回软件）

正常打开课程开始学习即可，用**全局热键**控制（看课的时候软件在后台）：

| 快捷键 | 功能 |
|--------|------|
| **F9** | 手动截图（怕漏检就按一下，保底截一张） |
| **F10** | 暂停 / 继续 |
| **F11** | 停止录制并生成逐字稿 |

界面按钮同样可用；主窗口里能实时看到字幕滚动和缩略图。

### 3. 结束后

- 停止录制后软件会**自动打开输出目录**，里面就是本次课程的完整记录：
  - `transcript.md` —— 图文混排逐字稿
  - `screenshots/` —— 所有 PPT 截图
  - `audio.wav` —— 原始音频（可用于重转写）
- 菜单 **导出 → 导出 Word 逐字稿**：生成 Word 文档（导出完成后也会自动打开所在目录）
- 菜单 **导出 → 离线重转写**：对准确率不满意时，用更大的 AI 模型重转整节课，效果明显提升（CPU 上较慢，长课程建议挂机跑）

### 4. 输出示例

生成的逐字稿长这样（Markdown，也可导出 Word）：

```markdown
# 课程逐字稿 - 2026-10-14 14-30-00

## [00:00:12] 第 1 页
![PPT 00-00-12](screenshots/000012_slide_001.png)

各位同学大家好，今天我们来讲一下……

## [00:03:45] 第 2 页
![PPT 00-03-45](screenshots/000225_slide_002.png)

接下来我们看第二个知识点……
```

### 5. 个性化设置

菜单 **设置 → 偏好设置** 里可以调整：

- **输出目录**：默认在软件目录下 `output/`，可改到任意盘符（支持"浏览"选目录，保存后长期生效）
- **语音识别**：模型大小（小=快、大=准）、设备（CPU/GPU）、静音分段参数
- **翻页检测**：检测频率、灵敏度阈值
- **AI 梳理（LLM）**：填入大模型 API Key（DeepSeek / 通义千问 / 智谱 / OpenAI 均可）——为下一版本的 AI 结构化总结做准备

所有配置保存在本地 `config/settings.json`，API Key 用 Windows 系统级加密存储，不会明文落盘。主窗口状态栏随时显示当前输出目录和配置文件位置，点击即可打开。

## 六、注意事项

1. **仅支持 Windows**（Win10/Win11 64 位）
2. 首次录制需下载语音模型（约 483MB），请耐心等待；之后离线可用
3. **AI 结构化总结**（把逐字稿自动归纳成"本节概览 / 知识点详解 / 要点总结"的教程文档）**将在下一版本发布**，本版请先试用录制与导出功能
4. 实时转写追求"跟得上"，准确率约 90%；要更高准确率请用"离线重转写"
5. 请勿用于未经授权的课程内容传播，录音版权自负
