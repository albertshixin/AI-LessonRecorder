|----------|-------------------------------------|

## 1. 引言

### 1.1 编写目的

本文档定义"在线课程录播器"软件的功能需求与非功能需求，作为后续方案设计、开发与验收的依据。

### 1.2 产品定位

一款运行于 Windows 桌面端的 AI 辅助学习工具。用户观看在线视频课程时，软件在后台：

1. 录制课程播放的声音；
2. 实时将声音转换为带时间戳的文字逐字稿；
3. 智能识别课程 PPT 页面的变化（翻页），自动截图并按时间戳插入逐字稿；
4. 停止录制后，合成"文字 + PPT 截图"混排的 Markdown 逐字稿文件；
5. 可将逐字稿导出为 Word 文档；
6. 可调用 AI 对逐字稿进行梳理、归纳、逻辑层级编排，生成一份详细的结构化课程教程文档（Word/MD），并在适当位置配 PPT 截图。

### 1.3 术语定义

| 术语 | 定义 |
|------|------|
| 逐字稿 | 按时间顺序完整记录课程讲解语音的文字稿 |
| 环回录音（Loopback） | 捕获系统正在播放的声音，而非麦克风输入 |
| 翻页检测 | 通过对比前后两帧画面的相似度，判断 PPT 是否切换到新页面 |
| 时间戳 | 形如 `[HH:MM:SS]` 的录制相对时间标记 |
| 教程文档 | AI 对逐字稿重新梳理、归纳后生成的结构化课程笔记 |

### 1.4 目标用户

- 需要复习/归档在线课程内容的学员；
- 需要将视频课程快速转化为图文笔记的知识工作者。

## 2. 总体描述

### 2.1 运行环境

| 项目 | 要求 |
|------|------|
| 操作系统 | Windows 10 64 位及以上 |
| 硬件 | 麦克风非必需；建议 8GB 以上内存（本地 ASR 需要） |
| 网络 | 使用云端 ASR / LLM 时需要联网；纯本地模式可离线 |

### 2.2 用户使用场景

1. 用户打开在线课程网页/客户端，启动本软件；
2. 选择录制范围（整个屏幕 / 指定窗口 / 指定区域）；
3. 点击"开始录制"，软件开始录音、转文字、检测翻页；
4. 课程结束后点击"停止录制"；
5. 软件自动生成逐字稿 MD 文件（含截图）；
6. 用户可选择：导出 Word 逐字稿 / 一键生成 AI 教程文档。

## 3. 功能需求

### FR-01 系统声音录制

- 采集**系统正在播放的声音**（WASAPI 环回），不依赖麦克风；
- 采集参数：采样率 16kHz、单声道、16bit PCM（满足 ASR 输入要求）；
- 同时将原始音频保存为文件（如 `audio.wav` 或 `m4a`），供复盘与二次转写；
- 支持显示实时音量电平，便于用户确认声音已被捕获。

### FR-02 实时语音转文本（ASR）

- 对录音流进行**流式/准实时**转写，字幕延迟目标 ≤ 5 秒；
- 每段文字带时间戳（该段语音开始的时间）；
- 支持中文为主，可配置英文/中英混合；
- 支持**本地引擎**（faster-whisper，离线可用）与**云端 API**（可配置）两种模式；
- 转写文本实时显示在主界面字幕区；
- 支持句级/段级分段，便于阅读。

### FR-03 PPT 翻页检测与截图

- 按可配置周期（默认 1~2 秒）抓取指定范围画面；
- 通过图像相似度算法（感知哈希 + 结构相似度）判断画面是否发生**内容性变化**：
  - 排除鼠标移动、光标闪烁、轻微水印/弹幕等噪声干扰；
  - 相似度阈值可配置；
- 判定翻页时：
  - 立即抓取一张**高清截图**（原始分辨率 PNG）；
  - 记录时间戳，编号保存（如 `000225_slide_003.png`）；
- 连续两页相似度回退到上一页（讲师翻回去）时，复用已有截图、只记录时间戳；
- 支持手动强制截图（快捷键/按钮），用于漏检补救。

### FR-04 时间轴同步与逐字稿 MD 生成

- 停止录制后，按时间轴合并"转写文本"与"截图事件"，生成结构化 MD 文件：

  ```markdown
  # 课程逐字稿 - {课程名} - {日期时间}

  ## [00:00:12] 第 1 页
  ![PPT 截图](screenshots/000012_slide_001.png)

  （该时间段内的转写文字……）

  ## [00:03:45] 第 2 页
  ![PPT 截图](screenshots/000225_slide_002.png)

  （该时间段内的转写文字……）
  ```

- 每次录制生成一个独立会话目录：`output/{会话名}/`，包含 `transcript.md`、`screenshots/`、`audio.*` 及会话元数据（JSON）。

### FR-05 Word 导出（逐字稿版）

- 将逐字稿 MD 转换为 `.docx`：
  - 标题、正文字体样式统一；
  - PPT 截图按时间顺序插入对应位置，宽度自适应页面；
  - 时间戳以可读格式展示；
- 支持选择仅导出文字（不含图片）。

### FR-06 AI 梳理总结（教程文档生成）

- 调用大语言模型（LLM），输入：完整逐字稿 + 各页截图的时间戳清单；
- 输出一份**详细的结构化教程文档**，要求：
  - 不是简单缩写，而是对内容做**逻辑层级的编排、梳理与归纳**；
  - 结构建议：课程概览 → 章节划分 → 知识点详解 → 要点总结/复习提纲；
  - 保留关键讲解原文（重要定义、公式、口诀等）；
  - 标注每个知识点对应的 PPT 截图位置，导出时自动插图；
  - 长课程内容需**分段处理后再汇总**（超过 LLM 上下文限制时）；
- 生成的教程文档同时保存为 MD 与 Word 两种格式；
- LLM 提供商、模型、API Key 均可配置（OpenAI 兼容协议）。

### FR-07 录制控制与会话管理

- 开始 / 暂停 / 恢复 / 停止录制；
- 录制时长显示；
- 会话历史列表：可查看、重新导出、重新生成 AI 教程；
- 异常保护：程序崩溃/断电后可恢复已完成的转写数据（本地缓存机制）。

### FR-08 设置管理

- ASR 引擎选择与参数（本地模型大小 / 云端 API）；
- 翻页检测灵敏度（阈值、抓屏周期）；
- LLM 配置（BaseURL / API Key / 模型名 / 温度）；
- 输出目录、语言、主题（浅色/深色）等；
- 配置持久化保存（`config/settings.json`）。

## 4. 非功能需求

| 编号 | 类别 | 要求 |
|------|------|------|
| NFR-01 | 性能 | 常规课程（≤2 小时）全程录制不丢帧、不死锁；截图+翻页判定单次耗时 ≤ 200ms |
| NFR-02 | 准确率 | 中文 ASR 字准确率：清晰课程音频 ≥ 90%（本地 medium 模型）；翻页检测漏检/误检率 ≤ 5% |
| NFR-03 | 资源占用 | 本地 ASR 模式内存峰值 ≤ 4GB；空闲态 CPU ≤ 5% |
| NFR-04 | 可靠性 | 单模块故障（如云端 LLM 超时）不影响录制与逐字稿生成，失败任务可重试 |
| NFR-05 | 易用性 | 三步内完成"开始录制"；主界面实时可见字幕流与最近截图 |
| NFR-06 | 隐私安全 | 本地模式下所有数据不出本机；API Key 加密存储于本地；不上传任何用户数据到开发者服务器 |
| NFR-07 | 可维护性 | 模块化架构，AI 能力层可替换（换 ASR/LLM 供应商不改核心代码） |
| NFR-08 | 兼容性 | Windows 10/11 x64；适配 100%/125%/150% DPI 缩放 |

---

## 5. 约束与假设

- 假设用户课程画面与声音来自**同一台 Windows 电脑**的播放；
- 在线课程有 DRM 保护时，不进行任何破解，仅以"屏幕画面变化检测 + 系统声音"方式工作；
- 云端 AI 模式下，逐字稿内容会发送至用户自行配置的 LLM 服务商，需用户知悉并同意。

---

## 6. 验收标准（摘要）

1. 录制一段 ≥ 30 分钟的在线课程，逐字稿完整、时间戳正确、无崩溃；
2. PPT 翻页 ≥ 20 次的课程，截图漏检 ≤ 1 次、明显误检 ≤ 1 次；
3. 生成的 MD 在 Typora/VSCode 中正常渲染，图片路径正确；
4. 导出的 Word 文档图文排版正确；
5. AI 教程文档结构完整、层级清晰、截图位置正确。
